NScript Framework Tests

Each suite runs on its own page so per-IIFE minified runtime metadata on Function.prototype does not collide across bundles. Open the page for the suite you want to run:

  • Sunlight.Framework.Test — core framework (IoC, observables, binders)
  • Sunlight.Framework.UI.Test — UI templates, skins, list views
  • Sunlight.Framework.Data.Test — data layer (IndexedDB, WebStore)
  • TodoApp.Test — TodoApp end-to-end

For headless / CI execution use node run-qunit.mjs (Playwright, one suite per browser page) or node run-tests.js (iterates the suite pages above).
